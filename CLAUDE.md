# Pousada Marrocos — site

Single-page site for Pousada Marrocos (Mulungu, Serra de Baturité, CE). Built on Lovable and edited here; the user writes in Portuguese (pt-BR) and is not a developer, so explain changes plainly and show screenshots before shipping.

## Lovable sync (read first)
- Repo: `homidadeba-jpg/oii-buddy-shine`, branch `main`. Pushing to `main` syncs to the Lovable editor at no credit cost; the user then clicks **Publish → Update** in Lovable to update the live site.
- Never force-push, rebase, amend or squash pushed commits (see `AGENTS.md`).
- `git pull` before starting work.
- `src/routeTree.gen.ts` is regenerated by `vite dev` / `vite build` and re-adds an `import type { createStart }` line that commit `5d2d12d` removed on purpose. Revert it (`git checkout -- src/routeTree.gen.ts`) before every commit.
- Use `npm install --no-package-lock`. The project's lockfile is `bun.lock`; do not add `package-lock.json`.

## Stack and layout
- TanStack Start + React 19 + Vite + TypeScript. Commands: `npm run dev` (port 8080 via `.claude/launch.json`), `npm run build`.
- `src/routes/index.tsx` — the whole page (photo catalog, hero, sections, lightbox, `MapArt` SVG).
- `src/components/Reserva.tsx` — booking panel that builds a WhatsApp message.
- `src/routes/__root.tsx` — `<head>` meta, font/hero preloads, and an inline script that adds `html.js`.
- `src/styles.css` — ~1,800 lines of layered Lovable overrides; **the blocks at the end win**. Prefer appending a scoped block over editing old rules. A cleanup of dead legacy rules is a known, deferred task.
- `public/fotos/` — 19 photos as WebP in `-720` and `-1600` variants (the large file is 1200px wide for portrait photos; srcset uses `1200w`). `public/fonts/` — self-hosted Bodoni Moda (400, 400 italic) and Manrope (500, 700).

## Design decisions (agreed with the user)
- Visual world: black `#050608`, cream `#f4efe6`, gold `#c9a24a`/`#e6c66a`, wine `#7a1f2b`. Titles in Bodoni Moda, text in Manrope. No eyebrow/kicker labels above headings. Minimum text size 11–12px; touch targets 44px.
- Hero "Venezianas": louvers stay closed (with the logo seal) until the hero photo decodes, then open; title wipes in by line; cream booking bar slides up. The louver/shutter effect is **only** for the page entrance — the user rejected it on section photos.
- Section photos: subtle rise (`translateY(28px)` + fade). Carousel/lightbox: slow crossfade.
- All motion pre-states are scoped to `html.js` so nothing is hidden without JS; `prefers-reduced-motion` shows everything static. This dev machine reports `prefers-reduced-motion: reduce`, so headless checks must emulate `no-preference` to see motion.
- Map is an illustrated SVG link to Google Maps (no iframe).

Availability, rooms, final price, capacity and pet rules are always "confirmados pelo atendimento".
